# Flash Sales API 接口测试与说明文档

## 概述

本文档详细说明了Flash Sales平台的所有API接口，包括功能描述、请求参数、响应格式和测试结果。所有测试基于运行在 `http://localhost:8000` 的本地开发环境。

## API 端点列表

### 1. 健康检查
- **端点**: `GET /health`
- **功能**: 检查API服务是否正常运行
- **认证**: 不需要
- **测试结果**: ✅ 正常
- **响应示例**:
```json
{"status": "ok"}
```

### 2. 用户认证
#### 2.1 用户注册
- **端点**: `POST /api/v1/auth/register`
- **功能**: 创建新用户账户
- **认证**: 不需要
- **请求体**:
```json
{
  "email": "user@example.com",
  "password": "securepassword",
  "username": "testuser"
}
```
- **测试状态**: ⚠️ 需要测试

#### 2.2 用户登录
- **端点**: `POST /api/v1/auth/token`
- **功能**: 获取访问令牌（JWT）
- **认证**: 不需要（但需要有效凭证）
- **请求格式**: `application/x-www-form-urlencoded`
- **参数**: `username`, `password`
- **测试状态**: ⚠️ 需要测试

### 3. 用户管理
#### 3.1 获取用户列表
- **端点**: `GET /api/v1/users/`
- **功能**: 获取所有用户列表（需要管理员权限）
- **认证**: 需要（Bearer Token）
- **测试状态**: ⚠️ 需要认证令牌

#### 3.2 获取特定用户
- **端点**: `GET /api/v1/users/{user_id}`
- **功能**: 获取指定用户的详细信息
- **认证**: 需要（Bearer Token）
- **测试状态**: ⚠️ 需要认证令牌

### 4. 产品管理
#### 4.1 获取产品列表
- **端点**: `GET /api/v1/products/`
- **功能**: 获取所有产品列表
- **认证**: 不需要
- **测试结果**: ✅ 正常（返回空数组，因为数据库中没有产品）
- **响应示例**:
```json
[]
```

#### 4.2 获取特定产品
- **端点**: `GET /api/v1/products/{product_id}`
- **功能**: 获取指定产品的详细信息
- **认证**: 不需要
- **测试状态**: ⚠️ 需要有效产品ID

### 5. 秒杀功能
#### 5.1 参与秒杀
- **端点**: `POST /api/v1/seckill/{seckill_product_id}`

- **测试状态**: ⚠️ 需要认证令牌和有效的秒杀产品ID

### 6. 订单管理

### 7. 支付功能

- **功能**: 处理订单支付（占位接口）

- **测试状态**: ⚠️ 需要认证令牌

### 8. 提示增强
#### 8.1 增强提示
- **端点**: `POST /api/v1/prompt/enhance`
- **功能**: 使用AI或规则增强用户输入的提示
- **认证**: 不需要
- **请求体**:
```json

  "prompt": "如何优化数据库查询？",
  "style": "professional",
  "language": "zh"

```
- **测试结果**: ⚠️ 请求超时（AI服务可能需要配置或更长时间）
- **问题分析**: 端点配置了10秒超时，但可能由于AI服务未正确配置或网络问题导致超时

## 问题解决

### 1. "Running release expired seckill stock" 消息问题
**问题描述**: 控制台每分钟打印"Running release expired seckill stock"消息
**根本原因**: 定时任务配置为每分钟运行一次库存释放任务
**解决方案**:
1. 已修改 `app/tasks/jobs.py`，将 `print()` 语句改为 `logger.debug()` 日志
2. 已修改 `app/tasks/scheduler.py`，将执行间隔从1分钟改为5分钟
3. 消息现在只会出现在调试日志中，不会污染控制台输出

### 2. 提示增强端点超时问题
**解决方案建议**:
1. 检查AI服务配置：
   - 确认 `.env` 文件中的 `OPENAI_API_KEY` 或 `SC_NET_API_KEY` 已正确设置
   - 确认 `SC_NET_API_BASE` 和 `SC_NET_MODEL` 配置正确
2. 增加超时时间：
   - 修改 `app/services/prompt_service.py` 中的请求超时设置
3. 实现降级机制：
   - 当AI服务不可用时，自动切换到规则增强模式

### 3. 数据库中没有测试数据
**问题**: 产品列表返回空数组
**解决方案**:
1. 创建测试数据脚本
2. 通过管理后台添加测试产品
3. 使用数据库初始化脚本
